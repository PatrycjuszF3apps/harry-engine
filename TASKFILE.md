# Task reference

Run any task with `task <name>`. List all tasks with `task --list`.

---

## Commands

| Task | Description |
|------|-------------|
| `build` | Rebuild all images and recreate containers |
| `up` | Start service |
| `down` | Stop and remove all containers |
| `stop` | Stop containers |
| `restart` | Recreate and restart all services (picks up config changes) |
| `run` | Run the application in the container |
| `shell` | Open an interactive bash shell in the `game_dev` container |
